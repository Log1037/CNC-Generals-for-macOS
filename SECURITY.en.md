# Security Policy

[中文](SECURITY.md) | [English](SECURITY.en.md)

## Supported scope

This repository supports security issues in the open-source engine, launcher, build scripts, and packaging workflow on the `main` branch. It does not distribute commercial game data, prebuilt private iOS apps or IPAs, or officially signed binaries.

Ordinary crashes, rendering bugs, compatibility problems, and feature requests are not security vulnerabilities. Report them through [GitHub Issues](https://github.com/Log1037/CNC-Generals-for-iOS-macOS/issues/new/choose).

## Report a vulnerability privately

Use GitHub's [private vulnerability report](https://github.com/Log1037/CNC-Generals-for-iOS-macOS/security/advisories/new). Do not first open a public issue, discussion, or social-media post.

Include:

- the affected commit, platform, and component;
- the practical security impact and required preconditions;
- minimal reproduction steps or a proof of concept;
- any mitigation you already tested.

Remove account details, private paths, Apple signing material, device UDIDs, and other secrets. Do not attach commercial game data or an app or IPA containing those assets.

The maintainer will acknowledge the report, assess its impact and scope, and coordinate disclosure once a fix can be published while respecting the reporter's preferences and upstream attribution.
