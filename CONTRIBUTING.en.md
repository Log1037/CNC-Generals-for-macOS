# Want to tinker with it?

[中文](CONTRIBUTING.md) | [English](CONTRIBUTING.en.md)

This is a personal-use fork maintained whenever it is useful, not a formal software project. Issues and pull requests are welcome, but there is no promise that every report will be handled and no need to write a full proposal first.

For a code contribution, this is usually enough:

- briefly explain what changed and why it was useful;
- mention the device and OS you tested when possible;
- keep each change focused enough to understand and undo;
- do not commit retail game data, an app or IPA containing it, private signing material, or closed-source plugin code;
- preserve author and upstream attribution.

If you are changing engine code, [AGENTS.md](AGENTS.md) records the build and code conventions that keep later work manageable. It is a reference, not an entrance exam.
