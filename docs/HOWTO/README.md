## 添加教程

1. 在本目录中新建 Markdown 文件。
2. 使用 `UPPERCASE_WITH_UNDERSCORES.md` 命名。
3. 面向发布的文档分别提供中文默认版和 `.en.md` 英文版。
4. 在中文和英文索引中同时增加链接。
5. 教程应包含用途、步骤、验证方法和常见问题。
