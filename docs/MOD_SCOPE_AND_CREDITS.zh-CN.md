# 模组范围与致谢

这是一个用于 macOS 日常游玩的个人 GeneralsX / Zero Hour 工作分支。这里的大部分修改，都是为了修复本地实际测试和游玩中遇到的 Bug 或兼容性问题；另有少量修改用于改善个人单机体验，包括显示缩放、Control Bar 布局、镜头范围、文字可读性、快捷操作和本地模组载入。

本仓库不能替代《将军》《零点行动》游戏本体，也不能替代 ProGen、GenTool 或其他社区项目。仓库不包含商业游戏资源；使用者仍须自行拥有合法游戏，并在本地提供原版 BIG 文件。

## 分支范围

- `main` 保存原版《零点行动》与两个发行版共用的 macOS 源码修改，以及该配置实际使用的通用模组覆盖文件。
- `progen` 从 `main` 继承，再加入 ProGen 专属源码修改和 ProGen 26 模组包。
- `INIZH.big`、音频、贴图、地图等游戏本体资源始终放在仓库之外。

仓库中跟踪的 `.big` 文件仅限社区模组或本地兼容性覆盖文件，用于保留可复现的实际载入组合。提交这些文件不改变原项目的作者身份、许可证或权利归属。

感谢 ProGen 的作者和维护者提供 ProGen 的玩法与资源内容。感谢 GenTool，以及本地配置中使用的 Control Bar Pro 内容。本 fork 所做的是围绕这些项目的本地兼容性修复和个人调整，不主张这些模组原始内容的作者身份。

本地载入组合还使用了 Expanded LAN Lobby Menu、DecalsZH 和 Boss AI 等覆盖文件。这里列出这些名称仅为说明实际使用范围，不表示本 fork 创作了对应原始模组。
