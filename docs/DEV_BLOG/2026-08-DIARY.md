# Development Diary - August 2026

---

## 2026-08-10: Prepare the personal macOS fork for public source release

The local customization moved from an external-disk working tree toward a reviewable GitHub fork.

### Attribution and documentation

- Added a bilingual customization section to the root README that identifies
  `ammaarreshi/Generals-Mac-iOS-iPad` as the direct upstream project.
- Added `NOTICE.md` with the complete EA → TheSuperHackers → Fighter19 → fbraz3 →
  ammaarreshi lineage and a prominent modified-version notice.
- Consolidated the engineering history into a bilingual overview plus complete
  Chinese and English editions.
- Added a bilingual macOS quick-start guide covering lawful Windows asset transfer,
  the required base/expansion directory pair, external disks, build/deploy, app
  packaging, signing checks, first launch, controls, and troubleshooting.

### Portable paths and launcher UX

- Removed the local `/Volumes/...` defaults from the engine, Cocoa launcher, and
  double-clickable Steam asset helper.
- The engine now derives direct-run fallbacks only from `GX_RUNTIME_ROOT`.
- The Cocoa launcher now resolves paths through environment overrides, remembered
  user choices, package-time paths, and standard runtime locations.
- When discovery fails, native open panels ask for Zero Hour (`INIZH.big`) and base
  Generals (`INI.big`) separately. They accept the marker file, its game directory,
  or a common parent and scan one level down for custom folder names.
- Successful selections are saved in the app's user defaults. Holding Option at
  launch or passing `--choose-game-dir` forces reselection.
- The packager now accepts `--game-dir`, `--generals-dir`, `--runtime`, `--engine`,
  `--icon`, and `--output`. Public packaging uses the icon already tracked by
  upstream; the machine-local custom ICNS remains ignored.

### Cadence cleanup

- Removed stale Cocoa launcher handling for `GXCinematicSpeedTenths` and
  `GX_CINEMATIC_LOGIC_FPS`.
- Removed the launcher's obsolete `renderFPS = max(renderFPS, logicFPS)` behavior.
- Standardized public and Defaults-button behavior at 60 render FPS and 1.0x game
  speed. Existing saved preferences such as 2.2x remain honored.

### Validation

- Objective-C launcher syntax check passed.
- Shell syntax checks passed for the packager, deploy, run, and asset helper scripts.
- A package built in the ignored `var/publish-check/` directory passed deep strict
  code-sign verification, plist validation, and launcher `--check`.
- Launcher normalization passed with three input forms: direct game directories,
  their common parent, and the two marker files themselves.
- The full `z_generals` macOS target rebuilt successfully. Existing third-party and
  legacy-engine warnings remain, including dependency deployment-target warnings;
  no new compilation error was introduced.

The game was not launched or automated during this release-preparation pass.
